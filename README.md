## ✨ Fitur Utama

- 🎨 **Gaya Neo-Brutalism**: Garis batas tegas, bayangan solid, dan kontras warna yang berani.
- 🌓 **Dark & Light Mode**: Mode gelap/terang otomatis tersimpan via `localStorage`.
- 🌐 **Dwi-Bahasa (ID/EN)**: Perpindahan bahasa Indonesia & Inggris secara *real-time*.
- 📱 **Responsif**: Optimal di perangkat seluler (*mobile*), tablet, dan *desktop*.
- 💼 **Bagian Lengkap**: *About*, *Skills*, *Projects* (Web & Desain Figma), *Services*, dan *Contact*.

## 🛠️ Teknologi

- **Frontend**: React 19, Vite, Tailwind CSS v4
- **Ikon**: Lucide React & Bootstrap Icons
- **State**: React Context API (Theme & Language)

## 🚀 Cara Menjalankan

1. **Klon repositori**:
   ```bash
   git clone https://github.com/ridhoadha25/ridho.dev.git
   cd ridho.dev
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
